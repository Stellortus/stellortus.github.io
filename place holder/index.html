算法-生成质数

Posted on 2026-08-11 Word count in article: 1.2k

前言

获取质数是常见的需求，假如我们想获取 2∼n2 \sim n2∼n（假设 n≤Nn \le Nn≤N，NNN 为已知的常数）的所有质数，应该怎么办呢？

两种选择

检查质数

首先不难想到，如果我们想达到这个目的，只需要检查这个范围内的每个数是不是质数就行了。

质数的定义是，除 111 和它本身以外没有其它因数的数，如果我们这么选择，那么在检查一个数 xxx 时，需要至少判断 2∼x2 \sim \sqrt x2∼x​ 中的每个数是否都不能被 xxx 整除（之所以是 x\sqrt xx​ 是因为：如果 y>xy \gt \sqrt xy>x​ 能被 xxx整除，那么 xy<x\dfrac{x}{y} \lt \sqrt xyx​<x​ 也能被 xxx 整除，所以检查小于 x\sqrt xx​的部分足矣）。

那么对于 2∼n2 \sim n2∼n 整体，就要检查 ∑n\displaystyle \sum \sqrt n∑n​ 次。估算时间复杂度约为 O(n⋅n)O(n \cdot \sqrt n)O(n⋅n​)。

筛去合数

有没有更好的做法呢？

已知合数的定义和质数相反，只要存在其它因子就算合数。

那么如果检查每个数是否为合数，就比检查质数方便得多，因为只需要找到一个反例即可。

怎么找合数呢？

埃拉托斯特尼筛法（埃筛）

初步想法

首先对于每个数，将它乘以 x∈Nx \in \mathbb Nx∈N 倍得到的一定是合数。

所以我们可以先从 222 开始，得到 4,6,8,⋯\red 4, \blue 6, 8, \cdots4,6,8,⋯，再从 333 开始，得到 6,9,12,⋯\blue 6, 9, 12, \cdots6,9,12,⋯，由于 4\red 44 被筛去，所以跳到 5→10,15,20,⋯5 \rightarrow 10, 15, 20, \cdots5→10,15,20,⋯，由于 6\blue 66 被筛去，所以跳到 7⋯7\cdots7⋯

另外，i>ni \gt \sqrt ni>n​ 时，i×ji \times ji×j 不可能 $ \lt n$，所以只需考虑 i∈[2,n]i \in \left[2,\sqrt n \right]i∈[2,n​] 即可。

计算时间复杂度

对于质数 222，我们筛去了 n2\dfrac n 22n​ 个合数，333 筛去了 n3\dfrac n 33n​ 个合数，⋯\cdots⋯

那么总操作次数就是 $\displaystyle \sum_p \dfrac n p $，由于 ∑1n≈log⁡n\displaystyle \sum \dfrac 1 n \approx \log n∑n1​≈logn，质数的数量也是 $ \dfrac 1 \log$ 级别，所以总时间复杂度为 O(nlog⁡log⁡n)O(n \log \log n)O(nloglogn)（注：严谨证明需借助积分，此处仅作直观理解故略去）。

欧拉筛（线性筛）

经过优化之后，我们还是可以发现一些问题。

比如 30=2×15=5×630 = 2 \times 15 = 5 \times 630=2×15=5×6，就会被筛去两次。

有没有什么办法，能让每个合数都只被筛去一次呢？

筛合数的办法

我们可以将一个合数描述为：最小质因子 ×\times× 其它。

这样就可以对所有的 i∈[2,n]i \in \left[2,n\right]i∈[2,n] 乘上质数 ppp，得到所有合数。

提前终止

首先，类似于刚才提到的 j≤ij \le ij≤i，你想到了可以限制 p≤ip \le ip≤i，防止 151515 被 3×53 \times 53×5 和 5×35 \times 35×3 同时筛去。

那么现在产生了一个新问题，12=6×2=4×312=6 \times 2 = 4 \times 312=6×2=4×3，要怎么避免它同时被 444 和 666 筛去呢？

之所以会有这种情况，是因为 444 有比 333 更小的质因数：222，所以才会产生 4×3=2×(2×3)=2×64 \times 3 = 2 \times (2 \times 3) = 2 \times 64×3=2×(2×3)=2×6 的情况。

那么既然对于任意一个数 xxx，都有 4×x=2×2x4 \times x = 2 \times 2x4×x=2×2x，那么 4x4x4x 这个数就不需要被 444 或 xxx 筛去了。

再比如，18=6×3=9×218 = 6 \times 3 = 9 \times 218=6×3=9×2，根据刚才的推理，因为 666 有更小的质因数 222，所以 181818 不该被 666 筛去。

所以，如果 ppp 是 iii 的因数，那么就应该停止 比 ppp 大的质数与 iii 相乘（因为 iii 有更小的质因数 ppp）。

综上，ppp 的终止条件有两个（至少一个成立就终止）：

  • p>ip \gt ip>i
  • imod  p=0i \mod p = 0imodp=0

由于当 i=pi = pi=p 时，imod  p=0i \mod p = 0imodp=0，所以只需考虑第二个条件即可。

大多数时候，使用埃筛就足够了，如果要追求极致速度，可以选择线性筛。

算法-二进制

Posted on 2025-06-27 Edited on 2026-07-18 Word count in article: 792

某种程度上讲，二进制也算一种算法？

前言

二进制从定义上讲只是一种数字表示方式。

与你们人类使用的十进制不同，二进制表示法中只有0和1两个数位。

例如，十进制下的 191919 在二进制下就表示为 100111001110011（注：所有二进制数均省略二进制表示法）。

十进制转换为二进制

二的幂分解

首先需要了解常用的二进制整数（即 222 的幂）：2,4,8,16,32,⋯2,4,8,16,32,\cdots2,4,8,16,32,⋯。

对于一个十进制数，从大到小分解：19=16+2+1=24+21+2019=16+2+1=2^4+2^1+2^019=16+2+1=24+21+20，所以就表示为 100111001110011。

倒序取余

这个方法更常用一些，但是原理不容易理解。具体操作过程如下：

  1. 对于一个数 N0N_0N0​，取它除以 222 的商 N1N_1N1​ 和余数 r0r_0r0​。
  2. 对得到的 N1N_1N1​ 重复第一步操作，得到商 N2N_2N2​ 和余数 r1r_1r1​。
  3. 重复操作至商 Nn=0N_n=0Nn​=0。
  4. 找到所有余数 r0,r1,⋯ ,rn−1r_0,r_1,\cdots,r_{n-1}r0​,r1​,⋯,rn−1​（共 nnn 个余数）。
  5. 将余数倒序书写：rn−1,⋯ ,r1,r0{r_{n-1}},\cdots,r_1,r_0rn−1​,⋯,r1​,r0​，得到的就是 N0N_0N0​ 的二进制表示法。

二进制转换为十进制

例如一个二进制数是 110101101011010，从右到左依次是第 0,1,2,3,40,1,2,3,40,1,2,3,4 位。

所以，十进制表示法就是：

1×24+1×23+0×22+1×21+0×201 \times 2^4+1 \times 2^3+0 \times 2^2+1 \times 2^1+0 \times 2^0 1×24+1×23+0×22+1×21+0×20

补码表示法

为了使用0和1表示负数，我们使用补码表示法。

具体是这样的：222 在二进制（一个字节）中是 0000 00100000\ 00100000 0010，为使 −2+2=0-2+2=0−2+2=0，只需要让 −2-2−2 用 1110 11101110\ 11101110 1110 表示（忽略溢出位）即可。

对于任意的一个正数，对其取反再加 111 就得到了对应负数的补码表示法。

那么反过来，一个负数先减 111 再取反就是对应的正数。

位操作/位运算

接下来进入程序部分！

首先，定义两个二进制数。

对于一般的编程语言，常见的位运算包括：

  • 与：两个数都为 111 时，结果才为 111。
  • 或：两个数只要有一个数为 111，结果就为 111。
  • 非：000 变成 111，111 变成 000，即取反。

int具有 323232 个二进制位，需要把所有的 000 都取反！

思考：如果a的类型是short或者long long，结果会有不同吗？

  • 异或：两个数相同的时候结果为 000，不同则为 111（最常用）。
  • 左移：将数字整体左移 nnn 位（注意：不要让它溢出！）
  • 右移：将数字整体右移 nnn 位。

补充

  • 运行客户端：选择runClient。
  • 运行服务端：选择runServer(通常不会选)。
  • 导出为Jar文件：在右边的Gradle中，依次选择Tasks->build->build，等待之后在左边文件夹build/libs中可以找到Mod的jar文件。
  • 修改mod版本：在gradle.properties中找到mod_version，修改即可。切忌把版本号改小！

代码解释

每条语句之后要有分号！！！

逐行：

  • package之后的内容和包名保持一致。

  • import暂时不用关注。

  • @Mod(string)：@Mod是注解，放在类的定义之前，表示下面的类是Mod主类，string是Mod ID。

  • public class Main：定义一个类，Main与上面的类名保持一致，大括号中是这个类的内容。它会被上一行标记为Mod主类。

  • public static final String MOD_ID：定义一个变量，它具有如下性质：

    • public：在任何地方都可以访问。

    • static：不需要创建一个对象(实例化)，使用类名.变量名的方式就可以访问(如Main.MOD_ID) 。

    • final：变量不可以被修改(常量)。

    • String：变量的类型为字符串(可以理解为一堆字就是字符串)。每个变量都要有类型，以下是常用的类型：

      • int：整型，存放整数。
      • float：浮点型(可以理解为小数)。
      • double：双精度浮点型，比float更精确。
      • String：字符串。

    • MOD_ID：表示这个变量的名称为MOD_ID。

  • "example_mod"：表示一个字符串，所有的字符串都要使用双引号。

  • LOGGER：日志记录器。可以很方便的调试程序，分不同的等级，常用的有info、error和debug。用法：LOGGER.info(string)，string表示日志输出的内容(字符串)。

  • //后表示注释，给人看的东西，随便写其实很少有人写。

Windows10任务栏配置

Posted on 2025-02-05 Edited on 2026-07-18 Word count in article: 185

1. 打开/关闭任务视图、搜索等

  • 右键任务栏空白处。
  • 找到想要打开/关闭的内容。
    • 如果是一级菜单，直接勾选即可。
    • 如果是二级菜单，点进去再勾选即可。

2. 任务栏全透明

这里不推荐 Windows 自带的透明功能。

  • 打开 Microsoft Store。
  • 搜索TranslucentTB。
  • 下载之后配置即可。

此处提供链接：https://apps.microsoft.com/detail/9pf4kz2vn4w9。

3. 任务栏居中

  • 进入https://github.com/mdhiggins/CenterTaskbar。
  • 在 Releases 中找到 exe 文件，下载。
  • 运行 exe 文件之后，任务栏就居中了。

可以设置开机自启动，方法如下：

  • Win+R，输入shell:startup。
  • 将 exe 文件扔进去！

这样每次开机都会运行一次，也就是开机自启动。
